# GBA-Niri
A Niri-wm configuration inspired by GBA games, including Metroid: Fusion, Metroid: Zero Mission, The Legends of Zelda: The Minish Cap, Pokémon RSE/FRLG, Mega Man Battle Network 3.


#### 1. THE GOAL OF THIS CONFIGURATION
The idea is of course trying to take inspiration from different GBA games and create a desktop that immediately recalls the user of a certain game.

#### 2. CURRENT STATE
The main configuration is basically done. It works, even though I would probably still try to perfect something, like the font, some parts of the gtk theme, and Alacritty colours. Some other things could be added later on, like Swaylock and an SDDM login in screen.


#### 3. HOW TO USE
The configuration was made and tested on Gentoo, which I daily drive. The files can be easily downloaded and modified according to preferences. PLEASE keep i mind that this was made for my own personal use, so maybe some files are missing because they're scripts I personally use and that maybe are not suitable for all users. The font is VT323 and the icons are from the Chicago95 icon pack. I haven't covered the installation of those on my Blog or on my YouTube channel. For example, I have a very simple updater file that's specific for Gentoo, so I chose not to upload it.
